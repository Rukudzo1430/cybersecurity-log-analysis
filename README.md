# cybersecurity log analysis
cybersecurity log analysis using python and pandas
Cybersecurity Log Analysis System

## About the Project
The Cybersecurity Log Analysis System is a beginner-friendly Python project that analyses security logs to help identify login patterns and potentially suspicious activity.

The project uses sample login records to demonstrate basic cybersecurity monitoring and data analysis.

## Project Objectives
- Analyse login attempts
- Count successful and failed logins
- Identify potentially suspicious login activity
- Practise Python programming and data analysis

## Features
- View security logs
- Analyse successful and failed login attempts
- Identify repeated failed login attempts
- Display analysis results in the terminal

## Technologies Used
- Python
- CSV file handling
- GitHub
- Visual Studio Code

## Project Files
- main.py — contains the Python program
- security_logs.csv — contains sample security log records
- README.md — documents the project

## How to Run the Project
1. Install Python.
2. Download or clone this repository.
3. Open the project folder in Visual Studio Code.
4. Open a terminal in the project folder.
5. Run the following command:

   py main.py

## Sample Data
This project uses fictional security log records for learning and demonstration purposes. No real passwords or confidential security information should be included.
